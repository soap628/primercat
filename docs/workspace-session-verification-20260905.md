# 引物工作区会话恢复

2026-09-05，本地验证记录，未部署。

## 行为

- qPCR 与常规 PCR 分别保存草稿、结果对应的原始请求、已完成结果及引物详情展开状态。
- qPCR 保存已完成的来源记录、参考复核和文献查询；未完成的补充资料可手动继续加载。
- PCR 保存已完成的成对特异性初筛及对应物种。
- 使用当前标签页的 sessionStorage，不新增后端存储，不使用 localStorage，不跨标签页同步。
- 初始化完成后才允许写快照，防止首轮空表单覆盖旧结果。存储不可用时使用页内内存回退并提醒刷新风险。
- 离页不重启设计；不恢复 loading、复制反馈、请求控制器。qPCR 未完成的设计需用户重新提交。
- 表单草稿与结果输入分离；输入改动后明确标识上次结果，防止错配。新设计成功前保留上次完成结果。
- 离页与新请求使旧请求失效，避免旧结果或参考资料覆盖新工作区。提供“清除本页”。
